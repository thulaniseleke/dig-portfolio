02 / Featured Project

Exploring taxi trip data.

A practical learning project involving data preparation, analysis and interactive reporting.

Data Analytics Project

NYC Taxi Data Analysis Dashboard

Tools used: Microsoft Excel and Power BI

Project overview

This project involved working with a New York City taxi dataset to practise preparing, exploring and presenting data. The work included cleaning the dataset, examining quantitative and categorical variables, creating charts and building interactive dashboard components.

Work undertaken

  • Prepared and cleaned the dataset for analysis using Power Query.
  • Explored quantitative and categorical variables using appropriate charts.
  • Created measures for summarising trip and fare information.
  • Added interactive slicers to help users filter dashboard information.
  • Worked on KPI elements to present important measures clearly.

Measures explored

Average Fare Average Tip Amount Average Trip Distance Total Revenue Total Trips

What I learned

The project helped me practise data preparation, chart selection, dashboard design and interactivity. It also reinforced the importance of checking data quality and ensuring that measures and visualisations communicate information clearly.
